Arcade High Scores (SQL en el navegador)

Esta tabla de puntajes corre sobre una base de datos SQLite real, compilada a WebAssembly y ejecutándose 100% en tu navegador (sin servidor). Cada vez que agregás un puntaje, se ejecuta una sentencia INSERT de verdad, y el ranking se calcula con un SELECT ... ORDER BY. Una pequeña demo de cómo aplico SQL a un contexto de videojuegos.
