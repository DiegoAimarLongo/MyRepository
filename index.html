// About me

Who I am

Hi! I'm Diego 👋, a Junior Software Developer from Rosario, Argentina, with a background in game development and software systems. I enjoy understanding how things work, solving problems, and turning ideas into clear, solid, and functional software.

I graduated from UNAHUR and I'm currently studying Systems Engineering at UTN. My main focus is on Object-Oriented Programming, software design, and building maintainable and scalable systems.

I'm particularly interested in backend development, desktop applications, and software architecture. I strive to write clean, structured, and maintainable code, applying best practices, design principles, and patterns when they genuinely add value.

I also have experience in game development using Unity and Godot Engine, where I apply the same software engineering fundamentals: logic, algorithms, data structures, architecture, and code organization.

I work comfortably in collaborative environments using Git, GitHub, Jira, and Scrum methodologies, and I especially enjoy learning, experimenting, and continuously improving the way I develop software.
